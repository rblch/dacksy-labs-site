2. Lo esencial

Solo tratamos datos personales cuando es necesario para el funcionamiento de este sitio web o para responder a tus consultas. Este sitio no usa cookies, no guarda nada en tu dispositivo, no utiliza herramientas de análisis ni de seguimiento y no carga contenido de terceros, como fuentes, mapas o vídeos.

3. Alojamiento y registros del servidor

Este sitio web está alojado en GitHub Pages, un servicio de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, EE. UU. Cuando visitas el sitio, tu navegador envía automáticamente información que GitHub guarda en archivos de registro del servidor:

  • dirección IP
  • fecha y hora del acceso
  • página o archivo solicitado
  • cantidad de datos transferidos y código de estado
  • tipo y versión del navegador y sistema operativo
  • URL de referencia (la página desde la que llegaste)

Estos datos son técnicamente necesarios para mostrarte el sitio web y garantizar su seguridad y estabilidad, por ejemplo para detectar y repeler ataques. La base jurídica es el art. 6, apdo. 1, letra f) del RGPD; nuestro interés legítimo es el funcionamiento seguro y fiable del sitio. GitHub decide cuánto tiempo conserva estos registros; nosotros no tenemos acceso a ellos.

Esto puede implicar la transferencia de datos a EE. UU. GitHub está certificado conforme al Marco de Privacidad de Datos UE-EE. UU., por lo que la transferencia está amparada por una decisión de adecuación de la Comisión Europea (art. 45 del RGPD). Encontrarás más información en la declaración de privacidad de GitHub.

4. Contacto por correo electrónico o teléfono

Si nos contactas por correo electrónico o por teléfono, tratamos los datos que nos facilites, como tu nombre, tu dirección de correo o número de teléfono y el contenido de tu consulta, para atender tu solicitud.

La base jurídica es el art. 6, apdo. 1, letra b) del RGPD cuando tu consulta está relacionada con un contrato o con medidas precontractuales y, en los demás casos, el art. 6, apdo. 1, letra f) del RGPD; nuestro interés legítimo es responder a las consultas. Eliminamos tus datos una vez que tu consulta se ha resuelto por completo, salvo que obligaciones legales de conservación lo impidan (por ejemplo, según el § 257 del Código de Comercio alemán o el § 147 del Código Tributario alemán).

Nuestro correo electrónico funciona con iCloud Mail, un servicio de Apple (para usuarios de la UE: Apple Distribution International Ltd., Hollyhill Industrial Estate, Hollyhill, Cork, Irlanda). Esto puede implicar la transferencia de datos a EE. UU.; Apple está certificada conforme al Marco de Privacidad de Datos UE-EE. UU. (art. 45 del RGPD).

5. Enlaces a otros sitios web

Este sitio enlaza a otros sitios web, por ejemplo a dackelapp.com. No se envía ningún dato al operador del sitio enlazado hasta que sigues el enlace. Allí se aplica la política de privacidad de ese sitio; nuestras apps tienen sus propios avisos de privacidad.

6. Cifrado

Este sitio web se sirve exclusivamente a través de una conexión cifrada (TLS). Lo reconocerás por el «https://» en la barra de direcciones de tu navegador.

7. Tus derechos

Tienes derecho de acceso a los datos que guardamos sobre ti (art. 15 del RGPD), así como de rectificación (art. 16), supresión (art. 17), limitación del tratamiento (art. 18) y portabilidad de los datos (art. 20). Solo tienes que escribirnos a support@rblch.com.

Derecho de oposición: cuando tratamos tus datos con base en el art. 6, apdo. 1, letra f) del RGPD, puedes oponerte al tratamiento en cualquier momento por motivos relacionados con tu situación particular (art. 21 del RGPD).

También puedes presentar una reclamación ante una autoridad de control de protección de datos (art. 77 del RGPD). La autoridad competente para nosotros es la Landesbeauftragte für Datenschutz und Informationsfreiheit Nordrhein-Westfalen, Kavalleriestraße 2–4, 40213 Düsseldorf, Alemania, www.ldi.nrw.de.

8. Otra información

No estás obligado a facilitarnos datos personales. Sin embargo, sin los datos de conexión indicados en el apartado 3, el sitio web no puede mostrarse. No tomamos decisiones automatizadas ni elaboramos perfiles.

Actualizamos esta política de privacidad cuando cambian el sitio web o los requisitos legales.
